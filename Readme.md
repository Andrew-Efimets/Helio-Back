Современная веб-платформа для общения и поиска новых знакомств. Проект позволяет пользователям находить людей из своего города, обмениваться сообщениями и делиться контентом.

Ключевые функции

·       Аутентификация и авторизация: регистрация, вход, восстановление пароля через SMS-сервис.

·       Поиск по городам: фильтрация пользователей по населенным пунктам для удобного поиска знакомств.

·       Интерактивный чат: мгновенный обмен текстовыми сообщениями между пользователями.

·       Публикация фото, видео и постов: возможность загружать изображения, видео и делиться моментами на своей странице (облачное хранение S3).

·       Система лайков: оценка постов, фотографий и видео других пользователей («Нравится»).

·       Личные профили: индивидуальные анкеты пользователей с информацией о себе.

Технологический стек

·       Frontend: HTML5, CSS3, JavaScript (Vue 3, SPA WebSocket)

·       Backend: PHP (Laravel API)

·       База данных: MySQL, Redis

·       Дополнительно: Git, Docker, Linux, SMS, AWS S3
